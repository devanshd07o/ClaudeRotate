# ⚡ ClaudeRotate — Beginner-Friendly Guide 👶

Welcome! **ClaudeRotate** helps you manage multiple Claude.ai accounts and transfer your chat sessions instantly when you hit message limits.

---

## 🟢 Part 1: How to Install the Desktop App (For Windows)

Follow these 3 easy steps:

1. **Download this folder** to your computer.
2. Open the folder and **double-click on `setup.vbs`**.
3. That's it! 🎉 An app window named **Claude Switcher** will automatically open. You can now use it to launch different Claude profiles with one click.

---

## 🟣 Part 2: How to Install the Chrome Extension

Follow these 4 super simple steps:

### Step 1: Open Chrome Extension Page
Open your Google Chrome browser, type this into the address bar at the top, and press **Enter**:
```text
chrome://extensions
```

### Step 2: Turn ON Developer Mode
In the **top-right corner** of the page, click the switch that says **Developer mode** so it turns **ON** (blue).

### Step 3: Load the Extension
1. Click the button in the **top-left corner** that says **Load unpacked**.
2. A file window will pop up. Select the **`extension`** folder inside this project folder.
3. You will now see **ClaudeRotate** in your Chrome extensions list! 🎉

### Step 4: Add your API Key
1. Click the puzzle icon 🧩 in the top-right corner of Chrome, then click **ClaudeRotate**.
2. Click the gear icon ⚙️ (Settings).
3. Paste your Groq or Gemini API Key and click **Save**.

---

## ⚡ How to Use ClaudeRotate (In 3 Seconds)

1. Open your chat on **https://claude.ai**.
2. Look at the **bottom-right corner** of your screen — you will see a purple button that says **Copy Handover**.
3. Click **Copy Handover**!
4. Open your new chat session and press **Ctrl + V** (Paste).
5. Done! Your new AI session will immediately understand everything from your previous session! 🚀
