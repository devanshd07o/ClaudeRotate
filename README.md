# ⚡ ClaudeRotate — Complete Step-by-Step Guide 👶

Welcome! **ClaudeRotate** helps you manage multiple Claude.ai accounts and transfer your chat sessions instantly when you hit message limits.

---

## 📥 STEP 1: How to Download this Project from GitHub

1. Scroll to the **very top** of this web page on GitHub.
2. Click the **green button** that says **`<> Code`** (located near the top right).
3. A small menu will open. Click on **Download ZIP**.
4. Wait a few seconds for the file to download to your computer.
5. Open your computer's **Downloads** folder (press `Win + E` on keyboard, then click Downloads).
6. Right-click on the **`ClaudeRotate-main.zip`** file and click **Extract All...** (or *Extract Here*).
7. Click the **Extract** button.
8. Now you will see a new un-zipped folder named **`ClaudeRotate-main`**. Open it!

---

## 🟢 STEP 2: How to Install the Desktop App (For Windows)

1. Inside your extracted **`ClaudeRotate-main`** folder, find the file named **`setup.vbs`**.
2. **Double-click** on **`setup.vbs`**.
3. A black setup window might blink for a second — this is completely normal!
4. Within a few seconds, an app window named **Claude Switcher** will open on your desktop screen. 🎉
5. You can now use this window to launch different Claude profiles with one click!

---

## 🟣 STEP 3: How to Install the Chrome Extension

### Step 3.1: Open Chrome Extension Settings
1. Open your **Google Chrome** browser.
2. Click on the address bar at the very top of Chrome (where website URLs are typed).
3. Type `chrome://extensions` and press **Enter** on your keyboard.

### Step 3.2: Turn ON Developer Mode
1. Look at the **top-right corner** of the page.
2. You will see a toggle switch labeled **Developer mode**.
3. Click the switch to turn it **ON** (the button will turn blue).

### Step 3.3: Load the Extension Folder
1. Look at the **top-left corner** of the page and click the button named **Load unpacked**.
2. A file folder selection window will pop up.
3. Go to your **Downloads** folder -> open **`ClaudeRotate-main`** -> select the **`extension`** folder.
4. Click **Select Folder** at the bottom.
5. You will now see **ClaudeRotate** appear in your list of Chrome extensions! 🎉

### Step 3.4: Add your API Key
1. Click the puzzle icon 🧩 at the top-right corner of Chrome (next to your profile picture).
2. Click on **ClaudeRotate** from the list.
3. In the extension window, click the gear icon ⚙️ (Settings).
4. Paste your **Groq** or **Gemini** API Key into the input box.
5. Click **Save**.

---

## ⚡ STEP 4: How to Use ClaudeRotate on Claude.ai (In 3 Seconds)

1. Open **https://claude.ai** in Chrome and open any chat thread.
2. Look at the **bottom-right corner** of your webpage screen.
3. You will see a purple floating button that says **Copy Handover**.
4. Click **Copy Handover**!
5. Open your new chat session tab.
6. Click inside the chat prompt box and press **Ctrl + V** on your keyboard (Paste).
7. Press Enter! Your new session immediately understands your entire context! 🚀
